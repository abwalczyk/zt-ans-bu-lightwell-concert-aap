= Module 3: Audit Trail

== Module Overview

In this module, you'll review the complete audit trail across all systems involved in the remediation. This demonstrates compliance and accountability for automated CVE remediation.

**Learning Objectives:**

* Review Concert's CVE status update
* Understand the complete audit trail across systems
* See how automated remediation maintains compliance

**Estimated time**: 10 minutes

== The Importance of Audit Trails

Automated remediation is powerful, but enterprises need accountability and compliance:

* **Regulatory requirements**: SOC 2, ISO 27001, PCI DSS require audit trails for security changes
* **Change management**: Track who/what made changes, when, and why
* **Incident response**: Investigate if a remediation caused issues
* **Compliance reporting**: Prove to auditors that CVEs were addressed

This lab demonstrates **end-to-end auditability** across:

* Security scanners
* IBM Concert
* Event-Driven Ansible
* Automation Orchestrator
* Gitea source control
* CI/CD pipeline
* Application deployment

== Step 1: Review Concert CVE Status

After successful remediation, the Automation Orchestrator workflow updates Concert's Action Center.

In the Automation Controller job output, look for:

[source,text]
----
TASK [Update Concert CVE status]
ok: [localhost]

TASK [Display Concert update response]
ok: [localhost] => {
    "concert_response": {
        "cve_id": "CVE-2026-52891",
        "status": "RESOLVED",
        "resolution_timestamp": "2026-09-17T10:35:42Z",
        "resolution_method": "AUTOMATED_LIGHTWELL_PACKAGE",
        "affected_apps_remaining": 0,
        "resolved_by": "automation-orchestrator",
        "verification": {
            "package": "PyYAML",
            "previous_version": "5.4.1",
            "current_version": "6.0.2",
            "deployment": "rhel01.example.com",
            "verified_at": "2026-09-17T10:35:40Z"
        }
    }
}
----

**Concert now shows**:

* **CVE Status**: RESOLVED (was OPEN)
* **Affected Applications**: 0 (was 1)
* **Resolution Time**: 5 minutes 42 seconds from initial alert
* **Resolution Method**: Automated via Lightwell package

Concert's Action Center maintains a historical record of:

* When the CVE was discovered
* Which applications were affected
* How it was remediated
* When it was verified as resolved

== Compliance Benefits

This audit trail satisfies compliance requirements:

**SOC 2 / ISO 27001**:

* Evidence of timely vulnerability remediation
* Automated controls reduce human error
* Complete change history with timestamps

**PCI DSS**:

* Critical vulnerabilities remediated within required timeframes
* Audit logs show who/what made changes
* Testing performed before deployment

**Change Management**:

* Automated approvals based on Concert risk scoring
* Code review via Git history
* Rollback capability via Git revert

**Incident Response**:

* If issues arise, full timeline available
* Exact version deployed is tracked
* Can correlate with monitoring/logging
