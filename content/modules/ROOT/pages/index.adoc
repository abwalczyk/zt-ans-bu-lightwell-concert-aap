= Concert + AAP + Lightwell Proactive Dependency Update Lab

== Lab Overview

Welcome to the Concert + AAP + Lightwell Proactive Dependency Update Lab. In this hands-on workshop, you'll learn how to automate enterprise-scale dependency updates the moment a trusted fix becomes available — using Red Hat Lightwell as the source of remediated packages, IBM Concert for portfolio-wide SBOM intelligence, Ansible Automation Platform for orchestration, and Tekton and ArgoCD for cloud-native delivery on OpenShift.

== What You'll Learn

* How Event-Driven Ansible reacts to a new Lightwell package landing in Artifactory
* How Concert identifies affected applications from enterprise-wide SBOM inventory
* How Concert's Arena View topology exposes cross-team deployment impact
* How Automation Orchestrator orchestrates the update workflow and routing decisions
* How Tekton builds and ArgoCD deploys the change with a complete audit trail

== Lab Scenario

Red Hat Lightwell has just published a remediated build of PyYAML — version 6.0.2, which fixes CVE-2026-52891 — into your Artifactory `lightwell-remediated` repository.

This is the key shift in this lab: you are not reacting to a vulnerability being *found*. You are reacting to a trusted fix becoming *available*.

**Without Concert**: You'd manually scan 500+ applications to work out which ones are still pinned to an older PyYAML. This takes hours or days, and by then the next package has landed.

**With Concert**: Concert's pre-indexed SBOM inventory instantly identifies the 12 applications (out of 537) still on an older version. Automation Orchestrator decides which ones to update now, and Tekton and ArgoCD deliver the change.

== Lab Environment

* **control**: Ansible Automation Platform with Automation Orchestrator and Event-Driven Ansible
* **OpenShift**: Tekton pipelines (`ci-cd` namespace) and ArgoCD (`openshift-gitops` namespace)
* **flask-api-app**: Target application, 3 replicas in the `production` namespace (PyYAML 5.4.1 → 6.0.2)
* **Artifactory**: Package store hosting the `lightwell-remediated` repository (event source)
* **Concert**: IBM Concert instance (SBOM inventory and topology, cloud-hosted)
* **Lightwell**: Red Hat Lightwell service (remediated packages)
