= Concert + AAP + Lightwell Proactive Dependency Update Lab
:toc: auto

A hands-on workshop demonstrating enterprise-scale, event-driven dependency updates using
Event-Driven Ansible to ingest Artifactory package events, Automation Orchestrator to
orchestrate the response, IBM Concert to provide enterprise-wide SBOM inventory and
dependency topology, Red Hat Lightwell for remediated dependencies, and Tekton and ArgoCD
for cloud-native build and GitOps delivery on OpenShift.

The trigger is proactive rather than reactive: the workflow starts when a trusted *fix*
becomes available, not when a vulnerability is discovered.

== Workshop Modules

[cols="1,2,2"]
|===
| Module | Focus | Hands-on exercises

| *DETECT -- Package Publish & Concert Impact Analysis*
| Red Hat Lightwell publishes a remediated PyYAML 6.0.2 build (fixing CVE-2026-52891) to
Artifactory. Event-Driven Ansible receives the webhook and triggers Automation Orchestrator.
Concert's pre-indexed SBOM inventory instantly identifies 12 affected applications out of 537
(including flask-api-app). Arena View topology shows deployment environments and downstream
dependencies. AO switch node routes to auto-update based on production deployment and severity.
| Publish package / simulate Artifactory webhook; observe EDA rulebook activation; review
Concert SBOM inventory by package (enterprise-wide); examine Concert Arena View topology;
watch AO switch node decision.

| *ORCHESTRATE -- Automation Orchestrator Update Workflow*
| Automation Orchestrator orchestrates the update: commit the dependency bump to Git, monitor
the Tekton PipelineRun (test, build, push image, update GitOps manifest), watch ArgoCD auto-sync
the rolling deployment, validate the result, and update Concert's SBOM.
| Execute Automation Orchestrator workflow; watch Tekton PipelineRun; observe ArgoCD sync and
rolling update; review job execution history; validate the running application.

| *VALIDATE -- Audit Trail Review*
| Review complete audit trail: Artifactory artifact provenance, EDA event receipt, Automation
Orchestrator execution history, Concert API queries and SBOM updates, Git commits, Tekton
pipeline logs and image provenance, ArgoCD sync history, application health checks.
| Review Automation Orchestrator execution history; examine Concert inventory (12 → 11 affected
apps); inspect ArgoCD rollback targets; generate compliance report with complete audit trail.
|===

== Architecture

[cols="1,2"]
|===
| Component | Role

| `control`       | AAP Controller 2.7+ with Automation Orchestrator and EDA
| `OpenShift`     | Tekton pipelines (`ci-cd`) and ArgoCD (`openshift-gitops`)
| `flask-api-app` | Target application, 3 replicas in the `production` namespace
| `Artifactory`   | Package store hosting `lightwell-remediated` (event source)
| `Quay`          | Container registry for images built by Tekton
| `Concert`       | IBM Concert instance (SBOM inventory and topology, shared, cloud-hosted)
| `Lightwell`     | Red Hat Lightwell service (remediated packages, shared)
|===

== Setup

The automated setup provisions infrastructure and configures the Tekton pipeline, ArgoCD
application, AAP job templates, and the target Flask application. Students will trigger the
update workflow and observe the full delivery lifecycle.

=== What the setup creates

* Flask application deployed to OpenShift with PyYAML 5.4.1 (3 replicas, `production` namespace)
* Tekton Pipeline, TriggerTemplate, and EventListener in the `ci-cd` namespace
* ArgoCD Application with automated sync policy watching the GitOps repository
* EDA rulebook and activation for Artifactory package webhook ingestion
* Automation Orchestrator workflow with Concert inventory/topology query nodes
* AAP job templates for Concert queries, Git update, Tekton monitoring, and validation
* Concert SBOM inventory pre-populated with application data

=== What attendees execute

* Publish a Lightwell package to Artifactory (or simulate the webhook)
* Observe EDA rulebook activation and Automation Orchestrator trigger
* Review Concert SBOM inventory results (12 affected apps from a 537-app portfolio)
* Review Concert Arena View topology (deployments, cross-team dependencies)
* Monitor Automation Orchestrator workflow execution (decision logic, routing)
* Watch the Tekton PipelineRun build, test, and publish the image
* Watch ArgoCD auto-sync the rolling deployment
* Review complete audit trail (Artifactory → EDA → AO → Concert → Tekton → ArgoCD → App)

== Prerequisites

* OpenShift cluster with OpenShift Pipelines (Tekton) and OpenShift GitOps (ArgoCD) operators
* OpenShift Virtualization cluster with RHDP provisioner
* AAP 2.7+ controller (shared or per-lab)
* IBM Concert instance (shared, cloud-hosted)
* Red Hat Lightwell access
* Artifactory instance with a `lightwell-remediated` repository and webhook support
* Container registry credentials (Quay)
* RHEL 9.x base image

== Lab Flow

1. **Artifactory Package Publish**: Lightwell publishes remediated PyYAML 6.0.2 to `lightwell-remediated`
2. **EDA Trigger**: EDA rulebook receives the webhook and triggers the Automation Orchestrator workflow
3. **Concert SBOM Inventory Query**: AO queries Concert by package → 12 affected apps out of 537 (including flask-api-app)
4. **Concert Topology Query**: AO queries Arena View → production deployment (3 replicas), 1 downstream dependency
5. **AO Routing Decision**: Switch node evaluates (production deployment + critical severity = auto-update)
6. **Git Update**: AO job template updates requirements.txt on branch `lightwell-update/pyyaml-6.0.2`, commits, pushes
7. **Tekton PipelineRun**: Clone → test → build image → push to Quay → update GitOps manifest
8. **ArgoCD Sync**: ArgoCD detects the manifest change and rolls out the new image across 3 replicas
9. **AO Validation**: Job template verifies ArgoCD sync/health, pod readiness, and application health endpoint
10. **Concert Inventory Update**: AO job template updates Concert SBOM (pyyaml: 5.4.1 → 6.0.2)
11. **Audit Trail**: Complete workflow history across Artifactory, EDA, AO, Concert, Git, Tekton, ArgoCD, application
